# TMA3084 Lab 1 - Pizza Order System

A simple Dart console program that uses a `switch` statement and `while` loops.

## Features
- Displays pizza prices: Small = 5 USD, Medium = 7 USD, Large = 10 USD
- Asks the user for pizza size and quantity
- Uses `switch` to determine the price and calculate the total payment
- Uses `while` loops for input validation and continuous ordering

## How to run
```
dart run pizza_order.dart
```
